# Synthetic-Augmentation-for-Censor-Aware-Fatigue-Life-Prediction-of-LPBF-Al

**Research objective:** Test whether selective, source-aware synthetic training can improve fatigue-life prediction for LPBF AlSi10Mg while retaining right-censored runouts and publication-level separation. A learned synthetic-data utility algorithm remains a **proposed direction**, not an implemented or validated result.

**Current evidence (8 October 2026):** The implemented S0 arm is same-teacher parametric self-distillation; S1 is a **fixed** filter based on observed runouts in the training source, not a learned gate. The [three-publication development comparison](docs/development_v2_four_arm_results_2026-10-06.md) did not meet its predeclared synthetic-augmentation advantage rule. The fixed-model [Beretta external check](docs/beretta_2022_esa_external_censor_aware_results_2026-10-08.md) (32 first exposures, including seven runouts) and [Al-Zuhairi preprint check](docs/al_zuhairi_30um_external_outcome_only_results_2026-10-07.md) (23 failures, no runouts) show small, descriptive aggregate changes. The [manuscript claim and evidence reconciliation](docs/manuscript_claim_evidence_reconciliation_2026-10-08.md) specifies supported and unsupported claims. No synthetic record is counted as an experimental specimen.

## Current experimental data

The [development v2 cohort](data/cohorts/development_v2_199_2026-10-06.csv) freezes 199 literature-exact first exposures: 172 failures and 27 runouts across four publication groups. It combines the original 66-record smooth core with 133 identified first exposures from Matušů 2026. See the [overlap and membership audit](docs/development_v2_overlap_and_membership_lock_2026-10-06.md) for exclusions, the three Matušů platform families, and source exclusions. The [feature and grouped-fold audit](docs/development_v2_feature_and_grouped_fold_audit_2026-10-06.md) confirms a 192-row R=0.1 publication-transfer track and a separate seven-row R=-1 Romano challenge. The previously scored 66-record folds remain historical development results. The Beretta and Al-Zuhairi checks are outside v2; reserved Strauß–Löwisch and Kempf campaigns remain unscored.

The earlier [no-author-response data decision](docs/no_author_response_decision.md) describes the 66-record core and a 75-record geometry sensitivity cohort. Five outcome-ambiguous Romano/Tognan rows and unlinked Roveda retests remain excluded. Cohort counts are data-inclusion decisions, not claims of model performance or journal sufficiency.
